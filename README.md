### What I've built

- **[Compass](https://github.com/EdwardBatt/Compass)** (open source): a guardrail and context system that keeps AI coding assistants aligned with a project's architecture and rules. I use it on most of my own projects.
- **Maestro:** an operations and workflow platform for a creative agency. React, Supabase (RLS, Realtime, Storage), 20 Edge Functions and OpenAI-powered document processing.
- **GGI esports platform:** tournaments, rankings, scheduled publishing and a Discord bot integration. SvelteKit, Supabase, BullMQ and Redis.
- **QR field-operations platform:** a bilingual PWA for merchant onboarding, field verification and agent payouts. Next.js, Supabase and PostGIS.
- **AI Document Intake:** automates accounts-payable data entry using OpenAI and Claude, with export to Xero and QuickBooks. Next.js 15 and shadcn/ui.

Most client work lives in private repositories. Case studies and demos are at **[edwardbatt.com](https://edwardbatt.com)**.

### How I work

- I start by mapping the process, then design the data model and build the smallest version that ships.
- I treat access control, tests and migrations as part of the feature, not an afterthought.
- I use AI-assisted development with guardrails, so speed doesn't come at the cost of architecture.
